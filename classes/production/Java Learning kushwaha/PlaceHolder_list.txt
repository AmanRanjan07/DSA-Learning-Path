** The + operator in Java serves two primary functions: arithmetic addition for numeric
 types and string concatenation for joining text strings

 **The + operator requires two targets (operands) to work, whereas
 the ! ("not") operator changes a single boolean target.

 ** Concatenation    str1 + str2        Combines both values into a brand new string
 **Reference Equality       str1 == str2        Checks if both variables share the same memory address.
 **Content Value Equality       str1.equals(str2)   Checks if the actual characters match sequentially.
